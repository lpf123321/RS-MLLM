# 星载容错与故障恢复（报告 §9）

## 机制
- **故障模型与覆盖边界**：单粒子翻转（SEU）作用于寄存器/锁存器/存储型状态，区分可纠正（ECC/EDAC）与不可纠正（MBU）类别。
- **不可变运行封套**：模型权重/配置哈希绑定，启动完整性校验，防止翻转变为"静默错误"。
- **运行时安全状态机**：启动 → 运行 → 降级 → 回滚 状态流转；检测到校验失败即进入降级/回滚，保障卫星侧推理稳定性。

## 实验
- A100（bf16 基座 + vLLM 0.26）实测：正常/注入翻转对比下的输出一致性、检测率与恢复耗时（详见报告 §9 测量数据）。
- 量化配置（W8A8-INT8 / W4A16-GPTQ）的位翻转敏感性为"量化容错"待测项（`quant_tol_probe` 敏感性探针），当前标为后续实验。

## 结论
容错机制在 bf16 在线推理路径上通过校验收口；低比特权重对翻转的敏感度将在决赛阶段实测补充。
